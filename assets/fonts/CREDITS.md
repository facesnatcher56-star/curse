# Fonts

Both fonts are licensed under the SIL Open Font License 1.1 (full texts beside them) and may be bundled and redistributed with the game.

- **Cinzel** (`Cinzel.ttf`, variable weight): headings, plate titles, menu buttons. The Cinzel Project Authors, https://github.com/NDISCOVER/Cinzel (OFL_Cinzel.txt).
- **Crimson Pro** (`CrimsonPro.ttf`, variable weight): body text everywhere (the project's default font, `gui/theme/custom_font`). The Crimson Pro Project Authors (OFL_CrimsonPro.txt).

Downloaded from the Google Fonts repository (https://github.com/google/fonts, `ofl/cinzel`, `ofl/crimsonpro`).
