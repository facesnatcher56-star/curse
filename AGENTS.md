# Notes for agents

Read [CLAUDE.md](CLAUDE.md) first. It holds the project rules for any agent, starting with the art direction (gritty and
versatile, see [docs/ART_DIRECTION.md](docs/ART_DIRECTION.md)), which applies to every asset however it is generated.

Shared local capabilities on this machine (Blender and the Godot MCP server `ziva-godot`) are documented in [docs/AGENT_ENVIRONMENT.md](docs/AGENT_ENVIRONMENT.md). All agents must use the Godot MCP server whenever working on this project to inspect scenes, check engine errors, run scenes, and validate nodes/physics—see [docs/MCP_GODOT.md](docs/MCP_GODOT.md) for full instructions and tool reference.
