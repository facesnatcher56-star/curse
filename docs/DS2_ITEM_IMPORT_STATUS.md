# DS2 equipment import status — 2026-10-11

## Legacy Curse equipment audit — 2026-10-11

The 18 original base IDs/models are repurposed through `ItemDef.stats_at` (DS2
weapon/armour curves) and `Items`/`AffixDb`, not a parallel legacy loot system.
The eight custom named pieces and Roadwarden set also use that same DS2 stat
vocabulary and equipment path. Their fixed bonuses/names are still Curse-authored,
**not** a one-for-one import of DS2 uniques or sets.

Removed the remaining body-armour roll-cost/roll-speed modifiers, greatsword
automatic cleave and free area slam, including generator data and tooltip claims.
All basic weapon swings (including Brutal Attack) hit only the engaged enemy;
explicit DS2 area powers remain. Per the subsequent owner decision, all living
body knockback and ragdolls are presentation only: no collision damage, wall bonus
damage/stun, status spreading, chain knockdowns or collision-driven prop attacks.
Direct attacks and powers retain their authored effects.
Saved item IDs/models are preserved; item reconstruction drops removed affix IDs
and ignores old raw stats. No production save editing is needed.

## Owner request

Bring the DS2 item/stat/affix catalogue across one-for-one. This is the target,
**not a claim that the playable import is complete**. Do not treat reference rows
as implemented mechanics or add unsupported rows to live loot.

## Source catalogue now available

`data/reference/ds2_equipment_catalog.json` is generated by
`python tools/extract_ds2_catalog.py` from the installed base game's Logic.ds2res.
It covers the player equipment families, spellbooks, crafted items, sets and
miscellaneous/quest weapons. Monster/NPC-only weapons, consumables and spells
themselves are outside this equipment snapshot.

The snapshot contains 768 named templates: 226 with normal/default rarity,
1 rare, 197 unique, 105 set pieces, and 239 crafted templates. These are source
template counts, not counts of distinct droppable base items: quest equipment,
cosmetic spellbooks and non-droppable templates are retained. Rows without an
explicit item level have an empty variant list rather than an invented level.

There are **304 affix rows and 27 set definitions**, including definitions not
necessarily represented in ordinary loot. The older notes' 22-set/198-unique
counts are not the counts produced by this extractor; do not force the data to
fit those older counts.

The snapshot preserves source IDs, names, item-level variants, requirements,
slot/class restrictions, weapon/armor expressions, inherited modifier fields,
effect ranges/roll ceilings, affix exclusion groups and set bonus **totals** at
each piece count. A set total is not an incremental bonus to add on top of every
previous total. Expressions remain strings; the extractor never executes them.
Source file hashes make the extraction reproducible. No DS2 scripts, models or
textures are copied into runtime assets. Icon identifiers are references only.
Custom-effect script behavior still needs separate tracing/implementation.

One source defect is explicit: AS7_set total_4 lacks an opening brace before its
12% dodge effect. The reader transcribes that brace without changing values;
the installed file is untouched. DS2 engine handling of this typo is unverified.

## Playable today

- Existing 18 Curse base items and the existing custom uniques/set remain intact;
  no saved item IDs are removed or rewritten.
- 25 supported affix families / 156 original source tiers are generated through
  `extract_ds2_affixes.py` and `write_affix_defs.py`.
- This pass adds Mana Steal and Mana per Hit with the original weapon-only tiers:
  `mana + flat bonus + percent / 100 * actual damage dealt`, clamped to maximum.
  Weapon hits qualify; spells, reflection, blocked and zero-damage hits do not.
- STR, DEX and INT already drive the hero's attributes, life/mana and damage;
  equipped attribute bonuses are included. Cutter derives attributes from his
  own Ranged experience, but does not yet have a full player-managed equipment
  and passive build.

Character growth uses DS2's human 12/11/11 start and class influence weights
(Melee 3/1/1, Ranged 1/3/1, either magic 1/1/3). The class-XP conversion and
per-class-level attribute increments remain documented approximations where
DS2's implementation is engine-side; these are not newly verified exact parity.

## Required to complete the one-for-one playable import

1. Implement missing weapon families/stances/projectiles, equip requirements and
   class-appropriate rolls without treating every weapon as a fighter sword.
2. Connect remaining damage/resistance types, ranged/nature modifiers, passive
   class/suite bonuses, conditional effects and their source restrictions.
3. Generate live base/unique/set definitions from the source snapshot, including
   authored value ranges and exact requirements. Keep existing save IDs as
   compatibility aliases; do not overwrite the current user's inventory.
4. Supply appropriate Curse-style models/icons and held/attack animations. Do not
   represent bows, staffs or axes as swords or claim the original art is imported.
5. Verify set totals, save migration, equipment, loot eligibility and combat with
   focused tests, plus visible checks on monitor 2 for new assets/animations.
